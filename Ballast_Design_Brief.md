Ballast is a desktop app (Wails, Go backend) that reliably uploads huge files (hundreds of GB) to Google Drive over unstable internet, auto-resuming after crashes, reboots, or dropped connections without re-sending completed bytes. It's built for field/low-connectivity professionals (journalists, researchers, remote workers) whose main anxiety is "did my upload actually go through, and will it recover if not." Design a full system covering: onboarding through Google sign-in, a file picker, an upload-progress view (each file uploads as one sequential stream, but multiple files can run concurrently), a history view, and a background/tray state for when uploads keep running with the window closed. Tone should be calm and reassuring by default, with an expandable detail view for power users who want real numbers (speed, retries, connection health) — and it should visually distinguish self-healing retries from errors that actually need the user's attention, keeping progress honest rather than smoothed or fake. Take creative and visual inspiration from https://21st.dev/ and https://www.tasteskill.dev/ for a modern, polished desktop aesthetic. Otherwise you have full creative freedom — not constrained by the current implementation. Deliver a reusable design system (colors incl. dark mode, type, spacing, components) plus full screen designs covering every state (empty, loading, error, multi-upload).
